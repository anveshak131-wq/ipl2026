# ✨ Admin Panel - Player Upload Summary

## 🎯 Quick Answer

In the **Admin Panel** → **Players Tab**, you can add player details **one by one**:

---

## 📍 How to Access

```
1. Click "Admin" in navbar
2. Enter password: admin2025
3. Click "Players" tab
4. Fill player form and click "Add Player"
```

---

## 📝 Player Form Fields

Fill in the following for each player:

| Field | Type | Example | Required |
|-------|------|---------|----------|
| **Team** | Dropdown | CSK, MI, RCB, etc. | ✅ |
| **Player Name** | Text | Ruturaj Gaikwad | ✅ |
| **Role** | Dropdown | Batsman, Bowler, All-rounder, Wicket Keeper | ✅ |
| **Country** | Text | India, Australia, England | ✅ |
| **Jersey Number** | Number | 1-99 | ✅ |

---

## ✅ Valid Values

**Roles:** 
- Batsman
- Bowler
- All-rounder
- Wicket Keeper

**Teams:** 
- CSK (Chennai Super Kings)
- MI (Mumbai Indians)
- RCB (Royal Challengers Bangalore)
- KKR (Kolkata Knight Riders)
- DC (Delhi Capitals)
- KXIP (Kings XI Punjab)
- RR (Rajasthan Royals)
- SRH (Sunrisers Hyderabad)
- GT (Gujarat Titans)
- LSG (Lucknow Super Giants)

---

## � How It Works

1. **Select Team** from dropdown
2. **Enter Player Name** (any text)
3. **Select Role** (choose from 4 options)
4. **Enter Country** (any country name)
5. **Enter Jersey Number** (1-99)
6. **Click "Add Player"** button
7. ✅ See success message
8. **Repeat** for next player

---

## 👥 Current Squad

After adding players, you'll see **"Current Squad"** section below the form showing all players added to selected team.
