# ⚡ Add Players - Quick Steps

## How to Add One Player

```
1. Click "Admin" → Enter password: admin2025
2. Go to "Players" tab
3. Select Team (dropdown)
4. Enter Player Name
5. Select Role (Batsman/Bowler/All-rounder/Wicket Keeper)
6. Enter Country
7. Enter Jersey Number (1-99)
8. Click "Add Player" button
9. ✅ Done! Repeat for next player
```
